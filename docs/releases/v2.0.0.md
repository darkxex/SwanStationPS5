**PSXS5 2.0.0**: a second emulator drawn on the GPU, up to 16x, plus automatic cheats and a better achievements screen.

## Beetle PSX HW, on the GPU

- **A second emulator: [Beetle PSX HW](https://github.com/libretro/beetle-psx-libretro)** (Mednafen), the accurate one, rendering on the PS5's GPU through Vulkan.
- **Internal resolution up to 16x** (native, 2x, 4x, 8x, 16x), at full speed: Parasite Eve holds 60 fps at 16x.
- **PGXP:** no more wobbling polygons or warping textures (Settings → Graphics → Precise geometry, on by default).
- **Emulator: Automatic** (Settings → System) picks Beetle when the BIOS for the game's region is there, and PCSX-ReARMed otherwise. You can also choose either one, per game.
- **One memory card per game, whichever emulator runs it.** Your existing saves work in Beetle; the memory card manager shows them as before.
- Save-state pictures, the quick-resume picture, scanlines, the TV frame and the menus all work over Beetle's picture.
- **The whole screen now reaches the TV through Vulkan**; the old path stays as a fallback.

**Beetle needs your own BIOS** for the game's region: `scph5500.bin` (Japan), `scph5501.bin` (USA), `scph5502.bin` (Europe) in `/data/PSXS5/bios/`. The PC tool recognises your dumps and gives them the right names:

```bash
python tools/psxs5_sync.py bios <your BIOS files> --host <PS5 IP>
```

## Cheats for every game, automatically

- PSXS5 knows all 1,961 PlayStation cheat files of libretro-database. When a game starts, it finds that game's file and downloads it. No PC tool and no setup.
- Smarter matching: "Disney-Pixar's" or "Disney-Pixar", "VII" or "7", "The Legend of..." or "Legend of..., The" all match; sequels never mix; full GameShark sets win over one-code files.
- Cheats work with both emulators.

## Achievements

- **Two tabs:** *Achievable* (closest first) and *Achieved*.
- **Progress bars** for counted achievements (18/80 dragons, 23%), and **a tracker in game** that pops up when one moves.
- Settings → Achievements: switch the unlock pop-ups and the tracker off if you'd rather not see them while playing.
- Fixed: discs weren't recognised (no achievements loaded) in 1.2.0.
- Every image format is recognised with both emulators, PBP and CHD included.
- When your version of a game isn't in any set (some PlayStation Store or patched images), PSXS5 now says so.

## Picture

- **Crop black edges** (Settings → Display): hides the black lines many games leave at the top and bottom, which an old TV hid. With *Stretch*, the picture fills the screen.
- With *Stretch*, the border and TV frame no longer shrink the picture.

## Your own covers

Suggested in [#1](https://github.com/SynoPiia/PSXS5/issues/1).

- **By name:** an image in `/data/PSXS5/covers/` named like the game's title, disc file or serial (`Crash Bandicoot.png`, `SCUS-94900.jpg`) is used automatically.
- **By hand:** on the shelf, △ (Details), then □. Choose any image from `covers/` or the game's folder, with a preview.

## Seeing your games

- **Unlocking `/data`:** PSXS5 asks LegacyJB, etaHEN (port 9028, with its *Legacy CMD server* on) and PS5SX2 Helper. Settings → System → *Allow PSXS5 in PS5SX2 Helper* adds PSXS5 to that helper's whitelist. The README's new *Unlocking /data* section explains which one to use.
- **Games copied another way** (FileZilla, a file manager, a USB drive): `python tools/psxs5_sync.py index --host <PS5 IP> --fix-cues` lists them for PSXS5 and repairs `.cue` files that point at renamed `.bin` files.
- The empty shelf now shows where games and the BIOS go, and why it's empty when `/data` is locked.
- Cheats are found even when `/data` is locked.

## Install or update

- **From 1.1 or newer:** Settings → About → *Check for updates*. This needs `/data` unlocked.
- **By hand:**
  1. Extract `PSXS5-v2.0.0.zip`.
  2. Copy `PPSA98510` to `/data/homebrew/` on the PS5, with permissions `777`. Or run:
     ```bash
     python tools/psxs5_sync.py app --app-dir PPSA98510 --host <PS5 IP>
     ```
  3. Close PSXS5 completely (PS button → Close Game) and start it again.

Your games, saves, states and settings stay as they are.

## Needs

- A jailbroken PS5 with etaHEN and kstuff (developed on firmware 13.60), and LegacyJB loaded so PSXS5 can see your games folder.
- ShadowMountPlus.
- **Your own games**, and for Beetle PSX HW **your own BIOS dump**.

> No BIOS files, games or keys are included, and none will be provided.

## Known limitations

- Beetle PSX HW needs the BIOS of the game's region; without it, PCSX-ReARMed runs the game (up to 2x).
- The first time a new effect appears, Beetle prepares its shader: a short hitch, once.
- Shaders (CRT filters beyond scanlines) aren't there yet.
