## New interface (1.1)

- **Shelf:**
  - Categories (L1/R1): All, Recently played, Favorites, Multi-disc, and each region.
  - Sorting with OPTIONS, and favorites with R3.
  - Tags for play time and last played, plus achievement progress.
  - A dark background, or one tinted by the selected cover (Settings → Library → Background).
- **Settings:**
  - Eight tabs, grouped cards and switches.
  - A help panel that explains each setting.
  - Per-game settings: L2/R2 switch between this game and all games.
- **Button mapping:** a DualSense drawing, any button to any PS1 button, and presets.
- **In-game menu:** a side panel with the cover, icons and save slots.
- **Snappier:** text and panels use the renderer's fast paths, and menu repeat is quicker.
- **Languages:** English, Français, Português (Portugal), Español (Latinoamérica) and 日本語.

## New in 1.2

- **Quick resume:** leave a game and press ✕ on it later to choose *Continue*, shown with a picture of where you were, or *Start over*.
- **Save-state thumbnails** on every slot.
- **Rewind and fast forward:** hold the touchpad and press L2 to rewind, or R2 to fast forward. Turn Rewind on in Settings → System first.
- **One-switch widescreen:** turns on the game's widescreen code and shows 16:9.
- **CRT look:** light or strong scanlines, and a soft glow or a 90s TV around the picture.
- **Up to 4 players** through a multitap.
- **Fan translations:** a `.ppf` patch next to a game is applied automatically.
- **Memory card manager:** see each card's saves, export them, and import `.mcr`, `.mcd`, `.srm` or `.gme` cards.
- **Achievements list** with badges and progress, in the in-game menu.
- **Settings from your phone:** turn it on and scan the QR code shown on the console.
- **Updates from GitHub:** PSXS5 tells you when a new release is out and installs it from Settings → About.

## Install or update

- **From 1.1 or newer:** Settings → About → *Check for updates* installs 1.2 directly. This needs `/data` unlocked through etaHEN, and the repository to be public.
- **From 1.0, or by hand:**
  1. Extract `PSXS5-v1.2.0.zip`.
  2. Copy `PPSA98510` to `/data/homebrew/` on the PS5, with permissions `777`. Or run:
     ```bash
     python tools/psxs5_sync.py app --app-dir PPSA98510 --host <PS5 IP>
     ```
  3. Close PSXS5 completely (PS button → Close Game) and start it again.

Your games, saves, states and settings stay as they are.

## Needs

- A jailbroken PS5 with etaHEN and kstuff (developed on firmware 13.60).
- ShadowMountPlus.
- **Your own games**, and optionally **your own BIOS dump**.

> No BIOS files, games or keys are included, and none will be provided.

## Known limitations

- Rendering is on the CPU: internal resolution goes up to 2x. A Vulkan renderer is in progress for 2.0.
- Rewind keeps about 8 seconds and uses around 200 MB of memory while it's on.
- Players 3 and 4 depend on the PS5 reporting the extra controllers to PSXS5.
