**PSXS5 2.1.1**: everything in [2.1.0](https://github.com/SynoPiia/PSXS5/releases/tag/v2.1.0), with a fixed updater.

## ⚠️ Coming from 2.0? Install this one by FTP

The in-app update in PSXS5 2.0.0 writes the new files without the permission the PS5 needs to start them, so after updating the console says *"Can't start the game or app"*. Your games, saves and settings are safe in `/data/PSXS5`.

- **Install 2.1.1 by FTP:** unzip it and copy the `PPSA98510` folder to `/data/homebrew/` (or `python tools/psxs5_sync.py app --app-dir PPSA98510 --host <PS5 IP>`).
- **Already stuck after updating from 2.0?** Copy the folder again by FTP. Or, in FileZilla, set the permissions of `eboot.bin`, `lapy.elf` and `sce_module/libc.prx` (in `/data/homebrew/PPSA98510`) to 777.

From 2.1.1 on, *Settings → About → Check for updates* installs new versions safely. PSXS5 2.0.0 won't offer updates anymore, so it can't break itself.

## Fixed

- The updater makes the new files executable, as an FTP copy does.
- It reads the whole list of releases.
